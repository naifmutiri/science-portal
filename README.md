# منصة العلوم — العروض التعليمية التفاعلية

بوابة تفاعلية تضم **٧١ درسًا** في مادة العلوم للمرحلة الابتدائية (الصفوف الأول إلى السادس)، الفصل الدراسي الأول، مع إثراءات تعليمية وصور توضيحية.

🔗 **رابط البوابة:** https://naifmutiri.github.io/science-portal/

## المحتوى

| الصف | عدد الدروس |
|---|---|
| الأول الابتدائي | ١١ |
| الثاني الابتدائي | ١٢ |
| الثالث الابتدائي | ١٢ |

## البنية

```
index.html                    الصفحة الرئيسية
0X_الصف_.../index.html        صفحة الصف (مرتبة بحسب الوحدات والفصول)
0X_الصف_.../.../الدرس.html    صفحة الدرس التفاعلية
assets/                       الأنماط والخطوط وصور الإثراءات
```

## الترخيص والحقوق

- خط Cairo مرخّص وفق `assets/Cairo-LICENSE.txt`.
- مصادر صور الإثراءات موثّقة في `assets/enrichment/photo-credits.json`.
